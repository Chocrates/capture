# Public items with no caller in the source, and why each is allowed.
#
# Every line is a claim somebody made in writing. An entry here says "this is
# reachable in a way the scan cannot see" or "this is a known gap with a
# recorded owner" — never "the check is inconvenient".
#
#   name: reason

# --- reachable in a way the scan cannot see -------------------------------
#
# `Pair`/`End` in capture-sync are an in-src test transport, the same category
# as `capture-core/src/testing.rs`, which this tool already exempts as
# SCAFFOLDING. Unlike that file they are not feature-gated and not in a file of
# their own, so the existing mechanism does not reach them. Moving them to
# `crates/capture-sync/src/testing.rs` behind a feature would remove both of
# these lines; until then they are claims rather than an oversight.

reaches: kept on purpose and says so. The fold answers "is this edit sequential" from branch tips instead, and this is the primitive the specification describes; it is retained and tested against the tip rule so the equivalence is checked rather than asserted. See its doc comment in crates/capture-core/src/fold.rs.
close: Pair is capture-sync's in-src test transport. Every caller is a test by construction, and this one causes a close mid-conversation, which Drop for End cannot express.
ends: the only way to obtain an End from Pair, capture-sync's in-src test transport. Used by four protocol test files; shipping code gets its Transport from a socket.

# --- known gaps, recorded ---------------------------------------------------
#
# Both of these are real: a capability the design states and no surface can
# reach. They are listed here rather than deleted because deleting them would
# destroy the only written statement of behaviour the system is supposed to
# have, and listed rather than fixed because each needs its own change.

evict: DESIGN §5.6 makes LRU blob eviction on constrained devices a shipped behaviour — "constrained devices evict on an LRU with a size cap and a 30-day default" — and no surface, policy or caller exists. The phone never frees blob space. Recorded 2026-10-03; needs its own change, with blobs::destroy (see below).
