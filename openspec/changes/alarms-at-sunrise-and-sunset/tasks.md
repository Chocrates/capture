## 3. Recognizer (capture-parse)

- [x] 3.1 Tests from the recognizer spec, including "watched the sunset", "sunset boulevard", `>sunset`, ±7 h offset asked.
  - "Asked" is the recognizer's existing way of asking: the reading scores 50, under the floor, so it is offered as a suggestion and never written unasked (`band::SUN_FAR`).
- [x] 3.2 Sun vocabulary and grammar; `GRAMMAR_VERSION` 10.
  - `SUN_WORDS` and `Class::SunWord`. A bare day set (`weekdays at sunrise`) recurs only before a sun phrase; widening bare `weekdays` everywhere is a separate decision. `h` is accepted as an hour only inside a sun phrase.
- [x] 3.3 promote.rs maps the new shapes to `When::Solar` / `SolarSeries`.
  - `Shape::Point(When::Sun)` → `Event{when: Solar}`; `Shape::SunRecurring` → `Series{when: Solar}` starting the capture's day. `split` keeps the sun and starts the new series on the boundary's day.
